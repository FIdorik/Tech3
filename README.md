# Практическая работа 3 — «Пульс»

Панель учебного проекта на Bootstrap 5.3.8 и JavaScript без сборки и сторонних JS-фреймворков. Решение выполнено по требованиям `example/README.md`: отдельного файла задания в репозитории нет.

## Запуск

Из корня репозитория:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8000. Остановить сервер: Ctrl+C. Открытие index.html через file:// не подходит: браузер ограничивает fetch локальных JSON. Для загрузки Bootstrap с CDN нужен интернет.

## Возможности

- Четыре показателя из dashboard.json, таблица восьми операций.
- Адаптивная сетка container / row / col, карточки, таблица, badges и progress Bootstrap.
- Совместная фильтрация по названию и статусу, счётчик и пустое состояние.
- Modal открывается через data-bs-toggle и data-bs-target; собственный обработчик формы меняет статус и вызывает Bootstrap Toast.
- Тексты success и warning берутся из notifications.json. Пустой обязательный статус вызывает предупреждение, успешное сохранение — уведомление.
- Состояния загрузки, ошибки HTTP/JSON/структуры данных и отсутствия Bootstrap JS; кнопка повторной загрузки.
- Изменения хранятся только в памяти страницы и сбрасываются после перезагрузки. Исходный dataset не перезаписывается.

## Разделение обязанностей

| Файл | Назначение |
| --- | --- |
| index.html | Семантическая структура, Bootstrap CSS/JS, контейнеры вывода и форма |
| css/styles.css | Оформление проекта без копирования внутренних стилей компонентов |
| js/data.js | Проверка структуры данных, фильтрация, расчёт доли завершённых операций |
| js/app.js | fetch, отображение через DOM/textContent, события и вызовы Bootstrap |
| dataset/ | Предоставленные входные данные и иллюстрация |
| example/ | Исходный учебный пример, оставлен без изменений |
| tests/data.test.js | Проверки данных, поиска, расчётов и ошибочных входов |

Bootstrap CSS отвечает за сетку и оформление; Bootstrap JavaScript — за открытие и закрытие modal, фокус и toast; наш JavaScript — за данные и прикладную логику. Доля завершённых операций считается отдельно от исходной метрики «Готовность»: в начальном состоянии это 3/8 ≈ 38% и 92% соответственно.

Официальная документация подключения Bootstrap: https://getbootstrap.com/docs/5.3/getting-started/introduction/ . Версия CDN зафиксирована, указаны integrity и crossorigin.

## Проверки

Node.js 18+; установка npm-пакетов не требуется:

```powershell
npm test
npm run check
```

Выполнено: 4 теста прошли, синтаксис обоих модулей проверен. В браузере проверены начальные показатели и 8 строк, modal, смена статуса операции 1 на «Готово», обновление прогресса до 50%, success toast и пустая поисковая выдача. При этой проверке ошибок и предупреждений в консоли не было.

Ручная проверка перед сдачей:

1. На ширинах 375, 768 и 1440 px проверить перестроение карточек, читаемость и отсутствие горизонтального скролла всей страницы. На узких экранах допускается прокрутка контейнера таблицы. Мобильная ширина автоматически не проверялась.
2. Совместить поиск «Операция 2» со статусами «Готово» и «Новая»; ожидать одну строку и пустую выдачу.
3. Открыть modal, проверить отмену и Escape. Выбрать пустой статус и сохранить: форма остаётся открытой, появляется warning toast. Выбрать допустимый статус: таблица и прогресс обновляются.
4. Для проверки ошибки заблокировать запрос dashboard.json в DevTools и перезагрузить страницу: появится alert. Снять блокировку и нажать «Повторить загрузку».
5. Перезагрузить страницу: изменения статусов сбросятся. Проверить управление Tab и видимость фокуса.
